이 실험적 기능은 [CSP Level 3](https://www.w3.org/TR/CSP3/)의 세분화된 디렉티브인 `script-src-elem`, `script-src-attr`, `style-src-elem`, `style-src-attr`에 대한 지원을 활성화합니다.

이 디렉티브를 사용하면 인라인 `<script>` 및 `<style>` 요소와 이벤트 핸들러 속성(예: `onclick`) 및 `style` 속성에 대해 별도의 콘텐츠 보안 정책을 적용할 수 있으며, 기본 `script-src` 및 `style-src` 디렉티브만으로는 불가능한 더 세밀한 제어가 가능합니다.

이 기능을 활성화하려면 Astro 설정에서 `experimental.cspLevel3`를 `true`로 설정하고 [`security.csp`](/ko/reference/configuration-reference/#securitycsp) 구성을 함께 추가하세요:

```js title="astro.config.mjs" ins={5}
import { defineConfig } from "astro/config"

export default defineConfig({
  experimental: {
    cspLevel3: true,
  },
  security: {
    csp: true,
  },
})
```

## 사용법

CSP Level 3가 활성화되면 [`security.csp`](/ko/reference/configuration-reference/#securitycsp) 구성에서 새로운 `scriptElemDirective` 및 `styleElemDirective` 옵션을 설정할 수 있으며, 기존 [`directives`](/ko/reference/configuration-reference/#securitycspdirectives) 배열을 통해 해당하는 `script-src-attr` 및 `style-src-attr` 값을 추가할 수 있습니다:

```js title="astro.config.mjs"
import { defineConfig } from "astro/config"

export default defineConfig({
  experimental: {
    cspLevel3: true,
  },
  security: {
    csp: {
      scriptElemDirective: {
        hashes: ['sha256-abc123'],
        resources: ['https://scripts.cdn.example.com/'],
      },
      styleElemDirective: {
        hashes: ['sha256-def456'],
        resources: ['https://styles.cdn.example.com/'],
      },
      directives: [
        "script-src-attr 'none'",
        "style-src-attr 'unsafe-inline'",
      ],
    },
  },
})
```

`Astro.csp`를 통해 런타임에 Level 3 리소스와 해시를 주입할 수도 있습니다:

```astro title="src/pages/index.astro"
---
Astro.csp.insertScriptElemResource('https://scripts.cdn.example.com/');
Astro.csp.insertStyleElemHash('sha256-abc123');
---

<html>
  <head><title>My Page</title></head>
  <body>
    <h1>Hello</h1>
  </body>
</html>
```

## 구성

### `scriptElemDirective`

**타입:** `{ hashes?: string[], resources?: string[] }`<br />

`script-src-elem` 디렉티브에 대한 구성 객체입니다. 어떤 인라인 `<script>` 요소의 실행을 허용할지 제어합니다.

#### `scriptElemDirective.hashes`

**타입:** `string[]`<br />
**기본값:** `[]`

`script-src-elem` 디렉티브에 추가할 CSP 해시(예: `sha256-...`, `sha384-...`, `sha512-...`) 배열입니다. 이 해시는 특정 인라인 스크립트 콘텐츠를 허가합니다.

#### `scriptElemDirective.resources`

**타입:** `string[]`<br />
**기본값:** `[]`

`script-src-elem` 디렉티브에 허용할 소스 URL 배열입니다.

### `styleElemDirective`

**타입:** `{ hashes?: string[], resources?: string[] }`<br />

`style-src-elem` 디렉티브에 대한 구성 객체입니다. 어떤 인라인 `<style>` 요소를 허용할지 제어합니다.

#### `styleElemDirective.hashes`

**타입:** `string[]`<br />
**기본값:** `[]`

`style-src-elem` 디렉티브에 추가할 CSP 해시 배열입니다.

#### `styleElemDirective.resources`

**타입:** `string[]`<br />
**기본값:** `[]`

`style-src-elem` 디렉티브에 허용할 소스 URL 배열입니다.

### 속성 디렉티브

`script-src-attr` 및 `style-src-attr` 디렉티브는 기존 [`directives`](/ko/reference/configuration-reference/#securitycspdirectives) 배열을 사용하여 설정할 수 있습니다:

- `script-src-attr`는 `onclick`, `onload` 등과 같은 이벤트 핸들러 속성을 제어합니다.
- `style-src-attr`는 HTML 요소의 `style` 속성을 제어합니다.

```js title="astro.config.mjs"
export default defineConfig({
  experimental: {
    cspLevel3: true,
  },
  security: {
    csp: {
      directives: [
        "script-src-attr 'none'",
        "style-src-attr 'unsafe-inline'",
      ],
    },
  },
})
```

## 런타임 API

`experimental.cspLevel3`가 활성화되면 `Astro.csp` 객체에서 네 가지 추가 메서드를 사용할 수 있습니다:

- `insertScriptElemResource(resource)` — `script-src-elem` 디렉티브에 소스 URL을 추가합니다
- `insertScriptElemHash(hash)` — `script-src-elem` 디렉티브에 해시를 추가합니다
- `insertStyleElemResource(resource)` — `style-src-elem` 디렉티브에 소스 URL을 추가합니다
- `insertStyleElemHash(hash)` — `style-src-elem` 디렉티브에 해시를 추가합니다

이 메서드는 [미들웨어](/ko/guides/middleware/)의 `context.csp` 객체에서도 사용할 수 있습니다:

```js title="src/middleware.ts"
export function onRequest(context, next) {
  context.csp.insertScriptElemResource('https://scripts.cdn.example.com/');
  return next();
}
```

## 작동 방식

CSP Level 3 디렉티브가 활성화되면, Astro는 기존 `script-src` 및 `style-src` 디렉티브와 함께 `script-src-elem` 및 `style-src-elem` 디렉티브를 CSP `<meta>` 태그에 추가합니다.

해당 Level 3 디렉티브에 대해 해시 또는 리소스 값을 구성한 경우, `script-src` 및 `style-src`에서 자동 생성된 해시가 `script-src-elem` 및 `style-src-elem`에 자동으로 상속됩니다. 따라서 해시를 수동으로 복제할 필요가 없습니다.

`script-src-attr` 및 `style-src-attr` 디렉티브는 자동으로 채워지지 않으며 `directives` 배열을 통해 명시적으로 구성해야 합니다.
